# Teyvat Social

Aplicación móvil en Flutter tematizada con el universo de Genshin Impact.
Taller/Parcial de Multimedia para Móviles.

## Secciones
- **Home**: Banner de evento, carrusel de regiones y publicaciones (`PostCard`) con botón "Me gusta".
- **Chats**: Lista de conversaciones con el widget reutilizable `ChatTile`.
- **Laboratorio de widgets**: Contador de Resina Original (0–160) con botones y `setState()`.

## Cómo ejecutarlo
1. Instala Flutter: https://docs.flutter.dev/get-started/install
2. Clona el repositorio y entra a la carpeta del proyecto.
3. Ejecuta `flutter pub get`.
4. Conecta un dispositivo o abre un emulador y ejecuta `flutter run`.

> Las imágenes se cargan desde internet. Si no hay conexión, se muestra un degradado con un icono.
